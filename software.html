Open-source tools developed by the lab for scientific machine learning, PDE inference, and computational biology.

PDE-STRIDE

Stability-inference framework for robust identification of differential equations from noisy, limited biological data using sparsity-promoting algorithms and stability selection.

Inverse-Dirichlet PINNs

Reliable training of Physics-Informed Neural Networks for multi-scale dynamical systems, using inverse Dirichlet weighting to balance competing loss terms automatically.

Physics-Informed ML Repository ↗

STENCIL-NET

Equation-free forecasting from data using learned discretization stencils. Enables accurate and stable long-term predictions of spatiotemporal dynamical systems.

PFI — Probability Flow Inference

Stochastic force inference via density estimation. Infers biophysical processes with intrinsic noise from cross-sectional single-cell data using probability flow matching.
