Air Quality Sensors — Starter Notebook¶

Applied Statistics and Data Science I · EN.553.413/613

Source: UCI Machine Learning Repository — Air Quality

Hourly measurements from a road-level monitoring station in an Italian city, March 2004 to February 2005. Two kinds of instruments sat side by side:

  • a certified reference analyzer (columns ending in (GT), "ground truth"), and
  • a device with five low-cost metal-oxide chemical sensors (columns starting with PT08).
Column Description Units
CO(GT) Carbon monoxide, reference analyzer mg/m³
PT08.S1(CO) Tin-oxide sensor, nominally targeting CO sensor response
NMHC(GT) Non-methane hydrocarbons, reference analyzer µg/m³
C6H6(GT) Benzene, reference analyzer µg/m³
PT08.S2(NMHC) Titania sensor, nominally targeting NMHC sensor response
NOx(GT) Nitrogen oxides, reference analyzer ppb
PT08.S3(NOx) Tungsten-oxide sensor, nominally targeting NOx sensor response
NO2(GT) Nitrogen dioxide, reference analyzer µg/m³
PT08.S4(NO2) Tungsten-oxide sensor, nominally targeting NO2 sensor response
PT08.S5(O3) Indium-oxide sensor, nominally targeting O3 sensor response
T Temperature °C
RH Relative humidity %
AH Absolute humidity —

In the raw file, missing values are coded as -200. The loading code below converts them to NaN.

This notebook only loads the data and makes a few basic plots. The analysis is up to you.

The first run downloads the data (internet required) and saves it in a local data/ folder.

1. Load the data¶

from pathlib import Path
import io, zipfile
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import requests

DATA = Path('data')
DATA.mkdir(exist_ok=True)
ZIP_PATH = DATA / 'air_quality_uci360.zip'
URL = 'https://archive.ics.uci.edu/static/public/360/air+quality.zip'

if not ZIP_PATH.is_file():
    r = requests.get(URL, timeout=120)
    r.raise_for_status()
    ZIP_PATH.write_bytes(r.content)

# The CSV uses ';' as separator and ',' as decimal mark; trailing empty columns/rows are dropped.
with zipfile.ZipFile(ZIP_PATH) as z:
    raw = pd.read_csv(io.BytesIO(z.read('AirQualityUCI.csv')), sep=';', decimal=',')
raw = raw.dropna(axis=1, how='all').dropna(axis=0, how='all')

raw['timestamp'] = pd.to_datetime(raw['Date'] + ' ' + raw['Time'], format='%d/%m/%Y %H.%M.%S')
df = raw.drop(columns=['Date', 'Time']).set_index('timestamp')
df = df.replace(-200, np.nan)   # -200 is the missing-value code

print(df.shape)
